# 主工作区视觉原型 · 第二轮

Scope: prototype 技能指定的全尺寸选择器，三个静态视觉方向；不连接任何生产接口。
未选定正式方向，本文件只描述探索，不改变生产设计。

## Overview
创作画布：图片在中央，提示词在画布底部，右侧是作品检查器，底边是紧凑任务带。
任务编排：主工作区按提示词、配方、队列、结果横向推进，强调批次状态与派发边界。
创作笔记：正文是提示词及每次生成配方，右侧是图片版本和详细元数据。

## Colors
画布为冷灰蓝深色，控制层为较亮的石墨蓝，蓝色只代表生成动作。
编排为白色与浅冷灰，钴蓝区分当前阶段，状态保留文字。
笔记为浅灰白正文、柔和紫色索引，字体保持工具语气，不使用展示衬线。

## Typography
系统字体与 Microsoft YaHei。正文 14px，标签 12px，主标题 26–30px。

## Layout
画布为中央工作面与单侧检查器，不沿用原页面输入/队列双卡片。
编排为四阶段空间，不是旧三栏变色。笔记为文档正文和旁注式版本册。
760px 以下均按内容顺序折为纵向，不缩小整张桌面布局。

## Components
只有比较器实现点击与快捷键。原型内操作以静态视觉控件呈现，表明不执行生图或队列操作。
选择器严格使用 prototype/PICKER.md 的样式和键盘行为。

## Do's and Don'ts
保留模型切换、推荐参数、抽奖数量、比例、历史、队列控制和图像详情的视觉位置。
所有演示状态标注，真实测试图只声明已有的真实尺寸和模型。
无 fetch、无生产引用、无动画展示、无自动选择正式方向。
