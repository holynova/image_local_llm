# 紧凑批量任务操作台

## Overview
用户明确参考 Photoshop 操作面板：深灰操作底色、紧凑菜单和工具选项栏、直角停靠区域、可折叠属性组。
以批量管理为核心，不使用大标题、巨大图片或稀疏卡片。本轮仅原型，生产代码未修改。
图层队列的核心是选中任务及批量动作；批次缩略图的核心是提示词归组及挑选结果；双区调度的核心是待派发和已执行状态分离。

## Colors
背景 #202024，面板 #2c2c31，控件 #38383f，边框 #494950。
前景 #f0f0f4，次级文字 #b8b8c5，选中面 #334d6d，操作色 #90bff9。
不同状态同时有文字标签，不单靠颜色辨认。

## Typography
系统 UI 字体及 Microsoft YaHei；正文 13px，标签 12px。数字仅用等宽作数据对齐。

## Layout
顶部菜单、选项工具栏、停靠主区、底部状态。滚动发生在任务或属性区而非整页无限变长。
图层队列：窄工具条、批次索引、中央任务列表和底部选中预览、右侧属性。
批次缩略图：批次索引、按提示词归组的网格、右侧可折叠配方。
双区调度：批次索引、中央待派发与当前/完成双区、底部批量输入、右侧检查器。
窄屏按区块堆叠，数据表只在自己的容器横向滚动。

## Components
选择器严格复用 prototype/PICKER.md。可点击选择任务、勾选、搜索过滤、折叠面板、切换属性页签。
业务按钮只说明原型用途，不执行真实生图、重排、停止或删除任务。
工作区无需表演性动画，切换即时。保留键盘焦点、原生 details 与 checkbox。
