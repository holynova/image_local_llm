本地绘图工作台 / 设计探索

三种布局，三种工作方式。

不是换肤：分别以创作、作品和批量作业为中心。每份原型都可以点击体验。
使用演示队列和两张实际模型测试图，不影响正式工作台。

A · 专注工作台

创作工具、实时预览、执行队列三栏并排。适合边生成边调整，希望所有信息同时可见。

B · 作品浏览室

大图与作品挑选优先，参数按需展开，队列收在下方。适合先看结果、筛选收藏和重复抽奖。

C · 批量生产台

提示词和任务形成作业表，模型配方放在检查器。适合大批量、多模型切换和管理执行顺序。

打开完整原型体验后，告诉我 A / B / C；也可以指定“以 A 为主，采用 B 的作品区”。正式网站暂未修改。
