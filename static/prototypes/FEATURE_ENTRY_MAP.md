# 暗色工作台精简版功能入口

这里只调整独立原型。正式 static/index.html / index.js 及全部 API 均未修改。
所有生产能力保留视觉入口；真实生图、服务与文件操作仍只在正式版运行。

| 功能 | 新入口 |
|---|---|
| 四模型选择、等待任务模型联动 | 创作区模型下拉 |
| 模型刷新与说明 | 模型旁“管理” |
| 提示词、每行批量、清空输入、入队 | 创作区 |
| 尺寸、实际比例、抽奖数量 | 默认显示的参数 |
| 步数、CFG、种子、前后缀、推荐说明与恢复 | 更多参数 |
| 提示词历史展开、载入、清空 | 提示词历史 |
| 队列暂停、恢复、进度、计数 | 队列顶栏 |
| 任务耗时 | 队列更多 → 显示耗时列 |
| 批次累计计时 | 队列更多 → 批次计时 |
| 打乱等待、停止当前、清空且保留图片 | 队列“更多” |
| 单任务置顶、跳过、删除 | 任务行“···” |
| 图片详情全部元数据、前后导航、下载、重新生成、点踩 | 点击图片 / 查看详情 |
| 收藏、复用提示词 | 预览区 / 作品卡 |
| 全部、收藏、点踩、隐藏点踩 | 展开作品集 |
| 下载全部、打开目录、清空画廊 | 作品集“更多” |
| 服务重启、停止、中英文、GitHub | 顶部“工具” |
| 日志、清空日志、本地目录 | 顶部“工具” |

减少的是默认展开内容和重复说明，不是功能。首屏保留一个主要动作“加入队列”。
